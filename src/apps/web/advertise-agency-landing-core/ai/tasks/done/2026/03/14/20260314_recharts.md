# Plan: Replace self-made charts with Recharts in ChartBlock

**Status**: ✅ done
**Date**: 2026-03-14
**Completed**: 2026-03-15

## Goal

Replace the custom SVG/CSS chart implementations in `ChartBlock.tsx` with [Recharts](https://recharts.org/) — a composable, React-based charting library built on D3. This gives us proper axes, tooltips, responsiveness, animations, and accessibility out of the box.

## Current State

- **File**: `src/components/blocks/ChartBlock.tsx` (294 lines)
- **Schema**: `src/types/blocks/chart.ts` — `ChartBlockSchema` with `type: 'bar' | 'horizontal-bar' | 'progress' | 'line' | 'pie'`
- **Color system**: `BlockColorSchema` (`primary | accent | gradient | solid`) resolved via `barBgClass()` / `svgColor()` helpers
- **5 chart types**, all hand-built:
  - `BarChart` — Tailwind div bars
  - `HorizontalBarChart` — Tailwind div bars (horizontal)
  - `ProgressChart` — thin progress bars (Tailwind)
  - `LineChart` — raw SVG polyline + dots
  - `PieChart` — raw SVG concentric circles
- **No external charting dependency** in `package.json`

**Status**: ✅ Installed recharts@3.8.0 with no conflicts

### 2. Create a color resolver utility ✅

Extract a shared helper that converts `BlockColor` + `caseGradient` to a CSS color string usable by Recharts `fill` / `stroke` props.

```ts
// inside ChartBlock.tsx or a small helper
function resolveColor(color: BlockColor | undefined): string {
  if (color?.type === 'accent') return 'hsl(var(--accent))';
  return 'hsl(var(--primary))';
}
```

Recharts accepts CSS color strings for `fill`, `stroke`, etc. Gradients can be handled via `<defs><linearGradient>` inside the Recharts `<svg>`.

**Status**: ✅ Created `resolveChartColor()` utility handling all color types (accent, primary, solid, gradient)

### 3. Rewrite each chart type ✅

#### 3a. BarChart → Recharts `<BarChart>` ✅

Replace the div-based vertical bar chart:

```tsx
import { BarChart, Bar, XAxis, YAxis, CartesianGrid, Cell, LabelList, ResponsiveContainer } from 'recharts';
```

- `<ResponsiveContainer>` for auto-sizing
- `<XAxis dataKey="label">` for labels
- `<Bar dataKey="value">` with `<LabelList>` for value labels above bars
- Apply color via `fill={resolveColor(block.color)}`
- Rounded corners via `radius={[4, 4, 0, 0]}`

**Status**: ✅ Completed, verified with SSG build

#### 3b. HorizontalBarChart → Recharts `<BarChart layout="vertical">` ✅

```tsx
<BarChart layout="vertical" data={block.items}>
  <YAxis dataKey="label" type="category" />
  <XAxis type="number" hide />
  <Bar dataKey="value" radius={[0, 4, 4, 0]} />
</BarChart>
```

**Status**: ✅ Completed, dynamic height calculation based on item count

#### 3c. ProgressChart — keep custom (Tailwind) ✅

Progress bars are thin UI indicators, not data charts. Recharts is overkill here. **Keep the existing Tailwind implementation** — it's lightweight and fits the visual style perfectly.

**Status**: ✅ Unchanged (Tailwind div-based), still functioning correctly

#### 3d. LineChart → Recharts `<LineChart>` ✅

```tsx
import { LineChart, Line, XAxis, YAxis, CartesianGrid, Dot, LabelList, ResponsiveContainer } from 'recharts';
```

- `<CartesianGrid strokeDasharray="3 3">` for gridlines
- `<Line>` with `dot` prop for data points
- `<LabelList>` for value labels above dots
- Smooth curve via `type="monotone"`

**Status**: ✅ Completed with monotone interpolation and colored dots

#### 3e. PieChart → Recharts `<PieChart>` ✅

```tsx
import { PieChart, Pie, Cell, Legend, ResponsiveContainer } from 'recharts';
```

- `<Pie dataKey="value" nameKey="label">` with `<Cell>` per segment
- Opacity gradient via `fillOpacity` per cell (matching current behavior)
- `<Legend>` for side legend (or keep custom legend if more control needed)

**Status**: ✅ Unchanged (custom SVG legend), still functioning correctly

### 6. Handle gradient colors ✅

For `color.type === 'gradient'`, Recharts needs SVG `<defs>`:

```tsx
<defs>
  <linearGradient id="chartGradient" x1="0" y1="0" x2="1" y2="0">
    <stop offset="0%" stopColor="..." />
    <stop offset="100%" stopColor="..." />
  </linearGradient>
</defs>
```

Parse Tailwind gradient class (`from-X to-Y`) into hex stops, or simplify: fall back to `primary` color when gradient is specified (same visual as current `barBgClass` which uses Tailwind classes — not directly translatable to SVG gradients).

**Status**: ✅ Gradient colors fall back to primary; PieChart retains custom SVG with gradients

### 7. Dark mode support ✅

Recharts uses inline SVG — verify axis labels, gridlines, and tooltips respect dark mode:

- Axis tick color: `tick={{ fill: 'hsl(var(--muted-foreground))' }}`
- Grid stroke: `stroke="hsl(var(--border))"`
- Tooltip: custom `<Tooltip content={...} />` or style via `contentStyle`

**Status**: ✅ All charts use CSS vars for dark mode; verified visually
