# Шаблоны контента

Каталог содержит безопасные обезличенные структуры. Он не копирует авторский
контент из `data/content/`. Полное описание полей, ограничений и MDX-блоков
находится в [русской документации](../../docs/content/template-reference.md).

Генератор использует значения шаблона для создания начального набора JSON и
копирует обе starter-статьи без валидации их MDX. Исходный каталог должен
содержать `manifest.json` с `schemaVersion` `1.0.0` и массивом `files`. Каждая
запись содержит относительные `path`, `kind` (`json` или `mdx`) и `output`.
Все записи `files` копируются при инициализации; отдельный список обязательных
файлов не нужен.

Генератор сортирует записи, нормализует root-relative пути медиа, отклоняет
небезопасные placeholders и создаёт детерминированный каталог. Запускайте
`node scripts/test-content-catalog.mjs` для проверки fixtures. Передавайте
исходник через `--source`, а запись в `data/content/` выполняйте только как
явный шаг инициализации нового сайта. Готовые данные нельзя молча
перезаписывать.
