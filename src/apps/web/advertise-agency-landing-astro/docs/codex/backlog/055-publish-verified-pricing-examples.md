## Goal

Give buyers usable budget guidance based on real agency pricing.

## Scope

- Collect approved dimensions, materials, included/excluded work, real photos,
  and prices or useful ranges for representative examples.
- Record currency, pricing date, current/historical context, applicable terms,
  cost factors, and situations requiring a custom estimate.
- Replace fictional pricing data using existing contracts and relevant real
  project links. Disable demo mode only after genuine approval.
- Verify visible terms, readable price labels, inquiry links, image behavior,
  light/dark themes, narrow widths, and enlarged text.

## Acceptance

- Every visible price/range has a traceable approved source and clear scope;
  historical amounts cannot be mistaken for a current guaranteed quote.
- Fictional examples/prices are absent from the production section; no
  approval flag is enabled merely to retain demo visibility.
