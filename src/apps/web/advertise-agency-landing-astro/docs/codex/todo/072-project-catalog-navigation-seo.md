# 072. Навигация и метаданные каталога

Статус: ожидает выполнения. Создано: 2026-10-10.
План: [Каталог проектов](../plan/20261010_050339_plan.md).
Зависимость: 071.

## Работы

- [ ] Оставить на главной первые 3 публичных проекта из общего источника.
- [ ] Добавить ссылку «Все проекты» в раздел главной, включая пустой список.
- [ ] Обновить пункт проектов в общем меню для перехода на `/projects/`.
  Проверить зависимые ссылки About, desktop/mobile меню и footer.
- [ ] На детальной странице направить хлебные крошки и возврат в каталог.
  Сохранить существующие URL проектов и якорь `/#projects`.
- [ ] Для возврата к результатам использовать безопасное состояние
  текущего каталога в sessionStorage, если оно доступно; прямой вход
  на проект и работа без JS возвращают в базовый `/projects/`.
- [ ] Добавить title, description и canonical базового каталога через
  существующий layout; параметры не создают отдельные SEO-страницы.
- [ ] Добавить базовый маршрут в sitemap при выполнении действующих
  условий индексации; не добавлять query-варианты и черновики.
- [ ] Согласовать поведение metadata demo-каталога с текущими правилами.
  Не активировать production индексацию в рамках этой задачи.

## Приёмка

- [ ] Каталог доступен из главной, меню и отдельного проекта.
- [ ] Возврат из карточки восстанавливает результаты в той же вкладке.
- [ ] Прямой переход в проект имеет рабочую ссылку на базовый каталог.
- [ ] Canonical не содержит q/category/page; sitemap не содержит их дублей.
- [ ] Старые ссылки и существующие формы заявок работают.

## Проверка

Проверить статические ссылки, metadata, sitemap с тестовым origin,
возврат к результатам и блокировку/недоступность sessionStorage.
