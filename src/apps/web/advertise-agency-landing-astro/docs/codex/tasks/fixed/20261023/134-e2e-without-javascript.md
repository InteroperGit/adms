## Шаги

1. Замени ручной browser.newContext исходного теста на test.describe с
   test.use({ javaScriptEnabled: false }). Так auto fixture блокировки
   применяется ко всем страницам. Ручное создание контекста здесь больше не
   требуется.

2. Сохрани исходный переход каталог→проект и запрет общей формы. Добавь реальный
   переход page/2 по нативной ссылке каталога: видна ссылка /projects/2/.

3. На /projects/1/ исходные ссылки галереи ведут на локальный /favicon.svg.
   Открой миниатюру обычным кликом, проверь URL; native dialog не обязан
   открываться без JS.

4. На /services/svetovye-bukvy/ submit формы световых букв disabled,
   предупреждение noscript видно. Счётчик endpoint запросов остаётся 0.

5. На /projects/1/ details диаграммы раскрывается и показывает все данные без
   canvas. Текст статьи и ссылки доступны.

6. Переход на privacy-policy и terms-of-use выполняется нативными ссылками
   футера; проверь main/h1 и успешный локальный ответ. Не требуй работающих JS
   меню или поиска.
