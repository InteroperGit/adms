## Шаги

1. Вынеси исходный прямой goto page/2 только если он дублирует новые проверки;
   catalog.spec.ts в этой задаче не меняй.

2. С главной каталога нажми реальную ссылку страницы 2 внутри
   [data-catalog-pagination]. Проверь /projects/page/2/, видимую ссылку
   /projects/2/ и aria-current=page у страницы 2.

3. Reload сохраняет страницу 2. Прямой goto страницы 3 показывает /projects/3/.

4. На границах проверь aria-disabled=true и tabindex=-1 у недоступной
   previous/next ссылки. Недоступный элемент не кликай: Playwright ожидает его
   доступности. Для отсутствия перехода достаточно проверки href/обработчика
   отдельным существующим unit-тестом; здесь проверяй UI.

5. Для category=sample доступны две страницы; переход на вторую сохраняет
   category и показывает /projects/2/. Back/Forward восстанавливают страницу и
   category.

6. Со страницы 2 измени поиск так, чтобы остался один результат: pathname
   возвращается к /projects/, лишняя пагинация скрывается.
