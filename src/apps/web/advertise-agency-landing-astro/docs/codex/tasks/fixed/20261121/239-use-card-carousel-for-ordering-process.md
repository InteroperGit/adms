## Handoff

`OrderingProcess` передаёт `OrderingStep` и массив `{ step, number }` в
`CardCarousel`. Ordered mode формирует `<ol>` с прямыми `<li>`; каждый item
компонент формирует содержимое пункта. Карточки занимают одну, две или три
полные позиции с частью следующей на ширинах 390/767, 768/1199 и от 1200px.
Ширины и snapping остаются scoped к секции заказа.

`CardCarousel` теперь требует Astro-компонент `Item` и непустой массив
объектов props. `astro/zod` проверяет массив, записи, label и ordered mode;
переданный default slot и неправильный `Item` завершаются явной ошибкой.
`ProductionGuidance` использует этот контракт через `GuidanceCard`; desktop grid
остаётся прежним. Для динамического рендера использован существующий в проекте
паттерн `AstroComponentFactory` из Catalog и проверена документация Astro по
`Astro.slots.has()` через Context7.
