# Добавить команды очистки временных файлов проекта

**Статус:** Выполнено

**Создана:** 2026-10-20

## Цель

Добавить понятные команды для удаления ненужных временных файлов и артефактов
разработки, включая содержимое `output/` и другие подтверждённые временные
каталоги проекта. Очистка должна быть предсказуемой и работать на Windows, macOS
и Linux.

## Реализация

- Добавлен `scripts/clean-temp.mjs` с фиксированным allowlist целей, preview по
  умолчанию, опцией `--apply`, обработкой отсутствующих путей и отказом от
  symlink-корня/целей.
- Обычная очистка удаляет только `.astro/`, `.playwright-cli/`, `coverage/` и
  `dist/`. Полное удаление `output/` выбирается отдельно флагом `--all`.
- Добавлены команды `clean:temp`, `clean:temp:apply`, `clean:temp:output` и
  `clean:temp:output:apply` в `package.json`.
- Описаны команды и границы удаления в `docs/rules/development/cleanup.md`;
  руководство настройки ссылается на эту документацию.
- Добавлены пять проверок очистки в `scripts/clean-temp.test.mjs`.

## Проверка

- `node --test scripts/clean-temp.test.mjs`: 5 тестов прошли.
- `node scripts/check-code-style.mjs`: пройдено для изменённых файлов.
- ESLint для нового скрипта и теста: пройден.
- Prettier для изменённых файлов: пройден после форматирования.
- `node scripts/clean-temp.mjs`: dry-run показал только четыре стандартные цели;
  `output/` не изменялся.
- `pnpm test:clean-temp` не запустился в sandbox: bundled pnpm завершился с
  `EPERM` при доступе к профилю Windows. Эквивалентный Node test runner запущен
  напрямую и прошёл.

## Правила использования

Команды без `apply` только показывают кандидатов. Команды `clean:temp:output` и
`clean:temp:output:apply` включают все файлы `output/`, в том числе логи,
скриншоты и доказательства проверок; следует проверить preview перед удалением.
Зависимости, локальные кэши, runtime-контент, fixtures, исходники и
пользовательские данные не являются целями очистки.
