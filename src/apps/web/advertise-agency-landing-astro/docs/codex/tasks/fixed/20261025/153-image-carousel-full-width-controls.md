# 153. Полноширинный Carousel и управление при наведении

Статус: завершено. Создано: 2026-10-25. Приоритет: средний.

## Цель и границы

Доработать общий `ImageCarousel`: компонент должен занимать всю ширину экрана, а
кнопки навигации должны выглядеть как простые боковые V-образные стрелки без
окантовки. На устройствах с указателем стрелки видны только при наведении на сам
Carousel.

Рабочие файлы: `src/components/ui/ImageCarousel.astro`,
`src/components/ui/CarouselControl.astro`, их colocated-тесты и связанные
проверки Carousel. Сохранить API компонента и текущие сценарии навигации.

## Реализация

- Перед началом перечитать `AGENTS.md`, применимые правила разработки и
  `astro-best-practices`.
- Обеспечить ширину Carousel от края до края viewport на всех поддерживаемых
  размерах экрана; проверить, что родительские контейнеры и варианты layout
  этому не мешают.
- Оформить кнопки предыдущего и следующего слайда как боковые V-образные
  шевроны. Удалить видимую рамку и сохранить интерактивную область кнопки,
  контраст, доступное имя и видимый клавиатурный focus.
- На устройствах с hover-capable указателем скрывать кнопки в обычном состоянии
  и показывать при наведении на область Carousel. Hover одного экземпляра не
  должен показывать кнопки другого.
- На сенсорных устройствах, где hover недоступен, оставить кнопки доступными.
  Фокус клавиатуры также должен делать кнопки видимыми.
- Сохранить работу ручной навигации, autoplay, reduced motion и статического
  fallback без JavaScript. Не добавлять runtime-состояние только для видимости.

## Приёмка и проверка

- Carousel занимает всю ширину viewport без горизонтальной прокрутки на desktop
  и mobile; проверены варианты `full` и `panel`.
- Стрелки визуально напоминают боковые V-образные шевроны и не имеют рамки.
- На desktop кнопки скрыты до hover над конкретным Carousel и видны во время
  наведения; при уходе указателя скрываются.
- На touch viewport кнопки доступны без hover; при клавиатурной навигации они
  видны и имеют различимый focus.
- Пройти colocated component/client suites и существующие E2E-проверки Carousel.
  Выполнить `pnpm check`, `pnpm check:style` и `pnpm format:check`.
- Записать фактические результаты проверок и изменённые файлы; после приёмки
  архивировать задачу согласно `docs/rules/development/task-management.md`.
