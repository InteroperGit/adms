## Handoff

На мобильных экранах стрелки скрыты, горизонтальная прокрутка доступна свайпом
и мышиным drag. Начиная с `48rem` карточки гарантий располагаются сеткой,
карусельная прокрутка и стрелки выключены.

`CardCarousel.astro` принимает карточки через слот, использует CSS Scroll Snap
и показывает кнопки только при переполнении. Touch-прокрутку обрабатывает
браузер; мышиный drag прокручивает viewport и отключает выделение карточек.
Широкая grid-раскладка гарантий ограничена стилями `ProductionGuidance`, поэтому
переиспользуемый `CardCarousel` сохраняет своё поведение на других ширинах.
`CardCarousel`, `ImageCarousel` и `CylinderCarousel` используют отдельные
локальные компоненты `CarouselControl`; lightbox подключает control из
`image-carousel`. Секция
гарантий сохраняет порядок и содержимое карточек. Последняя карточка имеет
правую snap-границу, чтобы окончание прокрутки совпадало с её правой кромкой.
Track занимает ширину viewport, а переполнение создают карточки, без хвоста
после последнего элемента. E2E fixture содержит шесть синтетических карточек
для проверки переполнения на мобильном и desktop без изменения runtime-контента.
