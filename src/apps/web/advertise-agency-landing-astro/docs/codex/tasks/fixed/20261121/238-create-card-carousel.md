## Scope

- Создать переиспользуемый компонент `CardCarousel.astro` в
  `src/components/ui/carousel/card-carousel/` с передачей карточек через слот.
- Подключить `CardCarousel` в `ProductionGuidance.astro` для секции
  «Наши гарантии». Сохранить содержание и порядок карточек.
- Использовать горизонтальную прокрутку с CSS Scroll Snap для свайпов.
- Использовать общий `CarouselControl` для стрелок в `CardCarousel` и
  `ImageCarousel`. Добавить в него режим оформления с круглыми подложками
  для `CardCarousel`. Текущее оформление оставить режимом по умолчанию.
- Ограничить листание началом и концом списка.
- На мобильных показывать одну карточку целиком и часть следующей справа.
- На планшетах и десктопах одновременно показывать столько компактных
  карточек целиком, сколько помещается в контейнере с учётом зазоров.
- Реализовать только ручное листание. Автопрокрутку и индикаторы слайдов
  исключить из реализации и API `CardCarousel`.

## Handoff

`CardCarousel.astro` принимает карточки через слот, использует CSS Scroll Snap
и показывает кнопки только при переполнении. Стрелки используют общий
`CarouselControl`; прежний стиль остаётся значением по умолчанию. Секция
гарантий сохраняет порядок и содержимое карточек. E2E fixture дополнен тремя
синтетическими карточками для проверки мобильного переполнения и desktop
состояния без изменения runtime-контента.
