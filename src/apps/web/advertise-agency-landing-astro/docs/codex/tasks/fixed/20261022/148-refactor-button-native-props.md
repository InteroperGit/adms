# 148. Типизировать нативные атрибуты Button

Статус: выполнено. Создано: 2026-10-22. Завершено: 2026-10-22. Приоритет:
средний.

## Основание и границы

В `src/components/ui/Button.astro` индексная сигнатура `[key: string]: unknown`
разрешает произвольные props, включая опечатки и неверные типы нативных
атрибутов. При этом компонент действительно передаёт остаточные атрибуты в `a`
или `button`. Контракт не описывает разницу между ссылкой и кнопкой.

Рабочие файлы: компонент, `Button.test.ts` и принятые в проекте проверки типов.
Сохранить варианты, размеры, slot и используемые вызовы Button.

## Реализация

- Прочитать правила проекта и навык `astro-best-practices`.
- Использовать `HTMLAttributes` из `astro/types` для ссылки и кнопки. Разделить
  ветви по `href`, согласовав пересекающиеся `type` и `class`.
- Убрать широкую индексную сигнатуру; сохранить необходимые `aria-*`, `data-*`,
  `tabindex`, `target`, `rel`, `disabled` и атрибуты формы.
- Сверить все места использования, включая NavLinks и ImageCarouselSlide. Не
  менять выбор HTML-элемента, значения по умолчанию и CSS-классы.

## Приёмка и проверка

- Валидные нативные атрибуты принимаются с корректными типами; ошибочные
  значения и опечатки отклоняются. Закрепить это проверками типов.
- Существующие render-тесты ссылки, кнопки, slot и передачи атрибутов проходят
  без ослабления assertions.
- Выполнить `pnpm exec vitest run src/components/ui/Button.test.ts`, проверки
  типов проекта, `pnpm check` и линтер изменённых файлов.
- Записать результаты и архивировать задачу по
  `docs/rules/development/task-management.md`.
