## Шаги

1. Открой /services/svetovye-bukvy/ и найди form[data-led-letters]. Перехвати
   /__fixture/inquiry и считай JSON запросов.

2. При contactMethod=phone имя, валидный телефон +79990000000 и consent
   достаточны для отправки без email.

3. При выборе contactMethod=email поле email становится required. Пустой email
   предотвращает запрос и получает фокус; корректный email разрешает отправку.

4. Проверь недопустимый телефон и widthCm=0: ошибки видны, запросов нет. Исправь
   обычным вводом.

5. Успешный payload содержит serviceId=svetovye-bukvy, выбранный contactMethod и
   введённые параметры. projectId на странице услуги отсутствует.

6. После подтверждённого receipt поля сброшены, contactMethod снова phone, email
   больше не required. После 503 значения сохранены. Сценарии транспорта не
   дублируй целиком из задачи 130.
