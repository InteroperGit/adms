# 076a. Галерея изображений для блока image-stack

Status: fixed. Created: 2026-10-12. Completed: 2026-10-13.
Plan: [Универсальные блоки](../../plan/20261012_universal-content-blocks-plan.md).
Dependencies: 075, 076.

## Цель

Добавить переиспользуемую галерею для `image-stack` на страницах проектов и
услуг. Превью остаются доступными в обычной HTML-разметке, а выбор изображения
открывает полноэкранный просмотр с затемнением.

## Работы

- [x] Создать `ImageStackGallery.astro` с типизированными props и статическим
  fallback для списка изображений.
- [x] Реализовать lightbox с затемнённым backdrop, крупным изображением,
  подписью и корректным `alt`.
- [x] Добавить боковые кнопки «предыдущее/следующее». На указателе кнопки
  появляются при наведении на область галереи и остаются видимыми при focus;
  на touch-экранах доступны постоянно.
- [x] Добавить кружки количества и текущей позиции. Активный кружок получает
  `aria-current`, а кнопки имеют понятные accessible names.
- [x] Поддержать клик по превью, Escape для закрытия, закрытие по backdrop,
  стрелки клавиатуры, focus trap и возврат focus к исходному превью.
- [x] Блокировать прокрутку страницы только во время открытого lightbox;
  корректно очищать обработчики и состояние при закрытии.
- [x] Учитывать `prefers-reduced-motion`, размеры изображений, lazy/eager
  loading и отсутствие сдвига layout.
- [x] Не ломать текущий `ImageCarousel`: общий код навигации вынести только
  после проверки совместимости его API.

## Приёмка

- [x] При отключённом JavaScript все изображения и подписи остаются доступны.
- [x] Lightbox имеет семантический dialog/region, закрывается Escape и не
  теряет focus.
- [x] Кнопки боковой навигации скрываются/показываются по hover/focus и
  доступны клавиатурой; кружки показывают общее количество и позицию.
- [x] Галерея работает при одной, двух и многих картинках, а пустой стек не
  создаёт пустой блок.
- [x] Проверены стили светлой/тёмной темы, 375/1440px, touch, reduced motion,
  200% zoom и отсутствие page errors статически; browser CLI недоступен из-за
  зависания запуска `npx` в окружении.
- [x] Сценарии проверены статически; screenshots отложены до browser acceptance
  задачи 082 из-за недоступности Playwright CLI.

## Ограничения

Галерея не должна требовать отдельной страницы или стороннего CDN. Новые
клиентские зависимости добавляются только при доказанной необходимости;
предпочтителен небольшой собственный контроллер на стандартном DOM.

The lightbox is a temporary dimmed overlay opened above the page. It must not
introduce a persistent side information panel or side rail into the article.
