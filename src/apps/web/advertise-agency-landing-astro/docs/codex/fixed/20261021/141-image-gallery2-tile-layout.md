# 141. Плиточная раскладка ImageGallery

Статус: выполнено. Создано: 2026-10-21. Завершено: 2026-10-21.

## Цель

Добавить плиточную раскладку в `ImageGallery`. После выбора пользователя
плиточная раскладка стала единственным режимом компонента.

## Требования к раскладке

- Изображения выводятся плитками в исходном порядке.
- На широких экранах сетка содержит три места (колонки) по горизонтали.
- При уменьшении ширины сетка последовательно переходит на две колонки, затем на
  одну. Конкретные точки перехода определить по ширине контента и показать на
  согласовании наброска.
- Первое изображение занимает два места. Для начального наброска считать это
  двумя соседними колонками в одной строке; подтвердить трактовку вместе со
  скриншотом. В двухколоночной сетке оно занимает всю строку, в одноколоночной —
  одну доступную колонку без переполнения.
- Остальные изображения занимают по одному месту. Сетка работает с одним, двумя,
  нечётным и большим количеством изображений; пустой набор не создаёт пустую
  галерею.
- Пропорции плиток, кадрирование, промежутки и внешний вид согласовать по
  скриншоту. Не растягивать изображения с искажением пропорций.
