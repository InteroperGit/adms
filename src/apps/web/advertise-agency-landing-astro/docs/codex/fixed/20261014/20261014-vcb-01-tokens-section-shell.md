# VCB-01 — Токены и общий каркас секций

Дата: 2026-10-14. Статус: completed (2026-10-14).

## Задача

Зависимости: нет. Добавить surface, border, radius, shadow, focus, spacing и
responsive tokens; согласовать общие заголовки, captions и акценты.

Статья должна восприниматься как единый линейный текст. Общий shell не
добавляет каждому `.content-block` фон, рамку, скругление, тень или внутреннюю
карточную обводку. Surface-токены остаются переиспользуемыми примитивами для
тех блоков, которым по смыслу нужна отдельная секция, например gallery или
form. Базовый контейнер отвечает только за ширину, вертикальный ритм,
переносы и anchor/focus поведение.

Готово, когда все renderers используют одну тему без фиксированных светлых
цветов, соседние блоки читаются как единый поток, а специальные surfaces
применяются только внутри задач конкретных block types.

Реализация: добавлены общие ContentBlock-токены для gap, spacing, heading,
caption, surface, border, radius, shadow, accent и focus ring. Контейнер
`ContentBlocks` использует токены для ритма, anchors и типографики, при этом
не добавляет карточное оформление каждому блоку.
