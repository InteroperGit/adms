## Шаги

1. Используй viewport 375×800 и закрывай cookie banner обычным кликом.

2. Сохрани исходные открытие, autofocus, Escape и возврат фокуса. Усиль trap: Tab с последнего элемента возвращает на первый; Shift+Tab с первого возвращает на последний.

3. Отдельно проверь кнопку [data-menu-close], повторное открытие и закрытие при переходе к desktop viewport 1440×900.

4. Выбери существующий hash-link из меню главной: клик закрывает dialog, URL получает hash, целевая секция получает фокус.

5. Со страницы /projects/ нажми ссылку меню на секцию главной. Проверь pathname '/', hash и существование целевого элемента.

6. Не активируй tel: и внешние messenger ссылки; здесь нужны внутренние переходы.
