# 068a. Упростить содержимое ProjectCard

Статус: выполнено. Создано: 2026-10-11. Завершено: 2026-10-11.
План: [Каталог проектов](../plan/20261010_050339_plan.md).
Зависимость: 068.

## Цель

Привести карточку проекта к короткой структуре каталога. После изображения
карточка должна содержать только четыре смысловых элемента: заголовок,
строку метаданных, описание и ссылку «Подробнее».

## Работы

- [ ] Обновить `src/components/cards/ProjectCard.astro`.
- [ ] Оставить заголовок проекта (`project.title`) отдельным `h3`.
- [ ] Добавить следующей строкой метаданные в формате «клиент, год заказа»:
  использовать `project.client` и `project.year`, без подписей «Клиент»
  или «Для бизнеса». Если год отсутствует, показывать только клиента без
  лишней запятой или заглушки.
- [ ] Оформить строку клиента и года визуально отдельно от обычного текста:
  использовать существующий muted-цвет и меньший размер, сохранив минимум
  44 px для интерактивных областей и читаемость в обеих темах.
- [ ] Оставить краткое описание (`project.shortDescription`) отдельным
  текстовым блоком после строки метаданных.
- [ ] Оставить одну ссылку с видимым текстом «Подробнее» и скрытым
  доступным уточнением названия проекта. Сохранить URL `/projects/{id}`,
  native-link поведение и иконку перехода.
- [ ] Удалить из текстовой части карточки notice, статус demo, отдельный
  блок «Клиент:» и любые другие текстовые блоки. Demo-обозначение карточки
  не переносить в новый блок; публикационные данные и детальная страница
  продолжают хранить статус отдельно.
- [ ] Не менять входной интерфейс `Props`, компонент изображения,
  страницу проекта и поведение ссылки без необходимости для этой задачи.
- [ ] Добавить состояние выделения всей `ProjectCard` при наведении мыши:
  изменить границу, фон или тень с умеренной интенсивностью, сохранив
  читаемость текста и отсутствие layout shift.
- [ ] Синхронизировать визуальное выделение с `:focus-within`, чтобы
  клавиатурный пользователь видел ту же выбранную карточку. Не требовать
  hover на сенсорных экранах; базовое состояние должно оставаться полным.
- [ ] Уважать `prefers-reduced-motion`: не использовать обязательную
  анимацию, а переход сделать мгновенным или отключаемым.

## Приёмка

- [ ] В текстовой части каждой карточки ровно: `h3`, строка
  «клиент, год» (или только клиент), описание и ссылка «Подробнее».
- [ ] В карточке нет notice, слов «Клиент», «Для бизнеса», статуса
  и других дополнительных текстовых блоков.
- [ ] Заголовок, описание и ссылка используют существующие данные проекта.
- [ ] У проектов с годом выводится год заказа; у проектов без года
  не появляется `undefined`, пустая запятая или визуальная заглушка.
- [ ] Метаданные отличаются от основного текста размером/цветом,
  остаются читаемыми в light/dark теме и не ломают длинные значения.
- [ ] Ссылка сохраняет доступное имя, клавиатурный фокус и адрес детали.
- [ ] Изображение и резервирование его пространства не регрессируют.
- [ ] Наведение на любую область карточки выделяет её без сдвига сетки;
  уход мыши возвращает базовый стиль. `:focus-within` даёт такой же эффект.
- [ ] Выделение работает в light/dark теме, не зависит от JavaScript и
  сохраняет контраст, видимый фокус и доступность ссылки.
