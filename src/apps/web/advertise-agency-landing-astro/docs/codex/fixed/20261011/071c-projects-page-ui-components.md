# 071c. Декомпозиция страницы Projects на Astro UI-компоненты

Статус: ожидает выполнения. Создано: 2026-10-11.
План: [Каталог проектов](../plan/20261010_050339_plan.md).
Зависимость: 071b.

## Цель

Разделить `src/pages/projects/index.astro` на небольшие переиспользуемые UI
компоненты Astro, сохранив текущую разметку, стили, доступность, SSR-навигацию
и клиентское поведение каталога.

## Работы

- [x] Выделить компонент оболочки каталога с хлебными крошками и общим
  контейнером страницы.
- [x] Выделить компонент панели поиска и фильтра категории с сохранением
  `role="search"`, labels, native controls и progressive enhancement.
- [x] Выделить компонент счётчика результатов и live-region для обновлений
  после поиска и фильтрации.
- [x] Выделить компонент сетки проектов, включая подготовку search metadata,
  category metadata и скрытие карточек при пагинации.
- [x] Выделить компонент состояния пустого каталога и отдельный компонент
  состояния пустого результата поиска.
- [x] Выделить компонент пагинации с SSR-ссылками, Mantine-подобным алгоритмом,
  URL-параметрами, `aria-current`, accessible labels и состояниями controls.
- [x] Перенести относящиеся к компонентам стили в их `<style>`-секции или
  согласованный общий слой без потери глобальных CSS-правил для динамических
  клиентских элементов.
- [x] Оставить `index.astro` страницей-компоновщиком: загрузка данных,
  вычисление page state и передача явно типизированных props компонентам.
- [x] Не дублировать логику фильтрации и пагинации; сохранить единый источник
  алгоритма для SSR и клиентского скрипта.

## Приёмка

- [x] `index.astro` содержит только загрузку данных, page-level state и
  композицию UI-компонентов.
- [x] Каждый новый компонент имеет понятную ответственность, типизированные
  props и короткий комментарий о назначении и accessibility assumptions.
- [x] Поиск, фильтр, счётчик, сетка, пустые состояния и пагинация визуально и
  функционально совпадают с текущей страницей.
- [x] Работают SSR, режим без JavaScript, query-параметры `q`, `category`,
  `page`, hash, Back/Forward и открытие ссылок в новой вкладке.
- [x] Сохраняются keyboard navigation, focus management, `aria-live`,
  `aria-current`, accessible labels и адаптивность 320–1440 px.
- [x] Удалены неиспользуемые стили, props и импорты; новые компоненты не
  создают циклических зависимостей.

## Проверка

Проверить каталог в браузере на 320, 375 и 1440 px, в обеих темах, мышью и
клавиатурой. Выполнить `pnpm check`, `pnpm build` и проверить прямые URL
страниц каталога с фильтрами и пагинацией.
