# 071a. Профессиональное оформление пагинации каталога проектов

Статус: ожидает выполнения. Создано: 2026-10-11.
План: [Каталог проектов](../plan/20261010_050339_plan.md).
Зависимость: 071.

## Работы

- [x] Переработать визуальный блок пагинации в едином стиле с каталогом:
  выровнять его по сетке карточек, задать ясную иерархию и достаточное
  визуальное отделение от списка.
- [x] Оформить кнопки предыдущей и следующей страниц, номера страниц и
  многоточие как единый набор контролов с понятными состояниями default,
  hover, focus-visible, active и disabled.
- [x] Выделить текущую страницу цветом и формой, согласованными с темой сайта,
  сохранив `aria-current="page"` и читаемый контраст.
- [x] Добавить аккуратные иконки или текстовые обозначения для переходов
  назад и вперёд; обеспечить понятные accessible name для каждой ссылки.
- [x] Сделать компонент адаптивным: на узких экранах сохранить удобный размер
  зоны нажатия, не допустить горизонтального переполнения и визуального шума.
- [x] Сохранить существующую URL-логику, порядок ссылок, обычную навигацию без
  JavaScript и фокус после перехода на страницу.
- [x] Не показывать пагинацию, когда результатов нет или доступна только одна
  страница.

## Приёмка

- [x] На широком экране пагинация выглядит как законченная панель под сеткой,
  а её элементы имеют одинаковую высоту, ритм отступов и состояние фокуса.
- [x] На ширине 320–375 px контролы помещаются в контейнер без обрезания и
  остаются удобными для касания.
- [x] У текущей, наведённой, сфокусированной и недоступной кнопок состояния
  различимы в светлой и тёмной темах.
- [x] Контраст текста и границ соответствует требованиям доступности; порядок
  клавиатурной навигации совпадает с визуальным порядком.
- [x] Переходы по ссылкам сохраняют `q`, `category` и `page`, а Back/Forward
  восстанавливают список и активную страницу.

## Проверка

Проверить страницу в браузере на ширинах 320, 375 и 1440 px, в обеих темах,
мышью и клавиатурой. После реализации выполнить `pnpm check` и `pnpm build`.
