# 070. Поиск и фильтрация проектов

Статус: ожидает выполнения. Создано: 2026-10-10.
План: [Каталог проектов](../plan/20261010_050339_plan.md).
Зависимость: 069.

## Работы

- [x] Добавить небольшой TypeScript-модуль без нового UI-фреймворка.
- [x] Реализовать поиск по названию, клиенту, краткому описанию и
  названию категории: регистр, лишние пробелы и «е/ё» не влияют.
  Все слова запроса искать в объединённых полях проекта.
- [x] Реализовать одиночный выбор категории и пункт «Все проекты».
  Фильтровать по единому полю `category`, заменившему `projectType`.
  Использовать подписанный native select, удобный на мобильном экране.
- [x] Применять запрос и категорию совместно до разбиения на страницы.
  Вынести чистую логику выборки для проверки независимо от DOM.
- [x] Добавить задержку ввода около 250 мс и отправку формы по Enter.
- [x] Обновлять счётчик, пустой результат и действие сброса.
- [x] Добавить подписи, фокус и ненавязчивое aria-live объявление
  количества найденных проектов. Не переставлять фокус при каждом вводе.
- [x] Использовать безопасные DOM API; запрос не вставлять через innerHTML.

## Приёмка

- [x] Частичный запрос, несколько слов, регистр и «е/ё» обработаны одинаково.
- [x] Выбранная категория сужает найденный список.
- [x] Очистка запроса сохраняет категорию; общий сброс снимает оба условия.
- [x] Пустые результаты не смешиваются с состоянием пустого каталога.
- [x] Отсутствующая категория не ломает поиск и показ всех проектов.

## Проверка

Проверить выборку на небольших фикстурах и работу клавиатуры в браузере.
