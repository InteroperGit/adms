# 071b. Пагинация каталога в стиле Mantine

Статус: ожидает выполнения. Создано: 2026-10-11.
План: [Каталог проектов](../plan/20261010_050339_plan.md).
Зависимость: 071a.
Референс: [Mantine Pagination](https://v3.mantine.dev/core/pagination/).

## Цель

Привести пагинацию каталога проектов к визуальной и поведенческой модели
Mantine Pagination, сохранив текущие URL-параметры, статическую навигацию и
стили сайта.

## Работы

- [x] Заменить текущую компоновку на компактную горизонтальную группу
  элементов: предыдущая страница, номера, многоточия и следующая страница.
- [x] Использовать одинаковые квадратные кнопки с единым размером, радиусом,
  межэлементным интервалом и выравниванием содержимого.
- [x] Сделать активную страницу визуально заполненной цветом primary,
  остальные страницы — спокойными outline-кнопками; сохранить hover,
  focus-visible, disabled и dark-theme состояния.
- [x] Добавить многоточия по модели Mantine: показывать начало и конец списка,
  соседей активной страницы и сокращать длинные диапазоны.
- [x] Реализовать параметры поведения, аналогичные `siblings` и `boundaries`,
  через константы или настройки компонента, чтобы число соседей и граничных
  страниц можно было менять без переписывания алгоритма.
- [x] Сохранить ссылки `<a>`, обычное открытие в новой вкладке, работу без
  JavaScript и параметры `q`, `category`, `page` в URL.
- [x] Привести accessible name к модели Mantine: отдельные названия для
  предыдущей, следующей, первой, последней страницы, номера страницы и
  многоточия; текущую страницу обозначить `aria-current="page"`.
- [x] Сохранить минимальную область нажатия 44 px, отсутствие горизонтального
  переполнения на 320–375 px и корректный порядок Tab-навигации.

## Приёмка

- [x] При большом числе страниц отображается компактная последовательность
  вида «назад, 1, …, соседние страницы, …, последняя, вперёд».
- [x] Активная страница, hover и focus визуально различимы в обеих темах.
- [x] Кнопки имеют одинаковые размеры и не прыгают при смене состояния.
- [x] Переходы сохраняют фильтры и поиск, Back/Forward восстанавливают страницу.
- [x] SSR-ссылки работают без JavaScript, а клиентское улучшение не создаёт
  дублирующих записей истории.
- [x] При одной странице или пустом результате пагинация скрыта.

## Проверка

Проверить каталог на 320, 375 и 1440 px мышью и клавиатурой, в светлой и
тёмной темах. Выполнить `pnpm check` и `pnpm build`.
