# Project improvement tasks

These tasks come from a review of the advertising agency Astro site. The existing `pages`, `layouts`, and `components/{ui,cards,sections}` structure should be retained. The production build passed and generated six pages at review time.

## Instructions for implementing agents

- Read `AGENTS.md` before starting and consult the relevant linked Astro guides.
- Implement only the assigned task; avoid unrelated refactoring.
- Inspect the current files before editing because another agent may have completed a related task.
- Run appropriate verification and report changes, results, and remaining limitations.
- If a development server is needed, use `astro dev --background`; manage it with `astro dev status`, `astro dev logs`, and `astro dev stop`.
- Do not invent agency claims, customer testimonials, project results, production domains, or consent requirements. Record missing information explicitly.
