## Proposed design direction

Use the visual language of fabricated signage: precise alignment, readable typography, restrained orange accents, and generous space around work imagery. Keep the strongest visual emphasis on genuine project photography when supplied, rather than decorative icons or oversized statistics. Preserve the recognizable orange identity while reducing stacked gradients, excessive shadows, and uniformly oversized rounded cards.

Use the implemented tokens from [design-system documentation](../../site/design-system.md) as the baseline, rather than reintroducing the original proposed palette. Brand orange is `#EA580C`; the butterfly logo has orange/blue wings and is already integrated into header/footer. Semantic primary colors are `#B2380A` in Light and `#FFA04D` in Dark. Measure contrast for new surfaces/states; retain accessible functional tokens independently of brand decoration.

Typography: assess locally hosted Manrope with Cyrillic support for headings and body, with a system sans-serif fallback; verify license, weights, and character coverage before adoption. Use a restrained responsive scale, comfortable line-height, and readable line lengths. Avoid uppercase decorative labels and arbitrary font proliferation.

Layout: compare a service-led opening with a work-led opening, then record the choice against actual media availability. Prefer service-led while real photography is missing. Keep the homepage h1 visually hidden per the user; use existing visible section headings and clear service copy without inserting a replacement oversized title.

```text
Desktop: brand | section links | settings (theme) | phone
         service introduction + actions | approved work visual
         project grid -> reviews -> contacts/map -> footer
Mobile:  brand | settings (theme) | menu
         introduction -> actions -> work -> reviews -> contacts
```

This direction is specific to outdoor signage and its materials. Do not substitute a generic SaaS card layout or add neon effects merely because the agency offers neon signage. Review screenshots and remove decoration that does not help visitors understand the services or contact the agency.

## Theme behavior required

Preserve the implemented Settings component: left «Тема» label with joined sun/moon/system icons, Russian accessible names/tooltips, no visible mode captions or current-theme caption, and clear checked/focus states. Settings and phone visible surfaces match; compact panel corners use the field radius. Unselected buttons use black/white hover in Light and contrasting orange hover in Dark; selected themes use a default cursor. System is the initial default; an explicit choice wins until changed. Persist only valid values, handle storage failures, follow OS changes only in System mode, and apply the effective theme before first paint. Update `data-theme` and `color-scheme` consistently. Preserve settings-aware auto-hide and navigation focus behavior. The external Yandex iframe retains its independent colors; document that limitation.

## Completion criteria and open inputs

- Consistent typography, spacing, surfaces, actions and focus states across all six routes and both themes.
- No clipping/overlap or horizontal overflow at 320px, 375px, 768px and 1440px, including 200% zoom/text checks. Fix previously observed header/review/cookie overflow.
- Keyboard navigation, dialog focus/Escape, section links, contact links, theme changes and cookie choices work; reduced motion is respected.
- Text/control contrast is measured against WCAG AA targets, not inferred from palette names.
- Check and build pass; browser screenshots, interaction results and limitations are recorded.
- Placeholder media remains clearly identified until approved assets arrive. See [media inventory](../../site/media.md). Agency favicon, production URL and actual project/review evidence are still pending; they should not block foundational layout/theme work.
- Document the final design tokens and theme behavior under `docs/site/`, with README links. No deployment or commit is implied by this plan.
