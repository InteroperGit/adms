# Project rule references

## Content storage

Keep all authored JSON and MDX content under `data/content/`, including
articles and content fixtures. Use subfolders to organize content. Keep
loaders, validators and typed exports in `src/`; do not store JSON or MDX
content there. Project configuration and package manifests are not content.

## Applicable rules

Read and follow the applicable rules before making changes:

- [Code style](docs/development/rules/code-style.md): all code changes.
- [Development server](docs/development/rules/dev-server.md): server commands.
- [Astro guides](docs/development/rules/astro-guides.md): related Astro tasks.
- [Sound notifications](docs/development/rules/sound-notifications.md):
  confirmation requests and task completion.
